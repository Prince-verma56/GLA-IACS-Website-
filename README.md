# FINAL QUALITY TEST

Before finishing, inspect the entire website and ask:

### Does it look AI generated?

If YES → remove unnecessary cards, gradients, icons and decorations.

### Does every section look like a collection of boxes?

If YES → redesign using editorial layouts.

### Is there too much animation?

If YES → reduce it by 70%.

### Is there too much rounded UI?

If YES → remove most rounded containers.

### Does the homepage immediately communicate GLA University + International Conference?

If NO → redesign the hero.

### Does the GLA University campus photograph dominate the homepage?

If NO → fix the hero.

### Does the website feel like a serious international medical conference?

If NO → simplify it.

### Does it feel trustworthy enough for professors, researchers, doctors and international delegates?

If NO → improve typography, spacing, photography and hierarchy.
